# Student Management System in C

A simple Student Management System built using C programming.

## Features

- Add Student
- Display Students
- Search Student by ID
- Update Student
- Delete Student
- Save and Load Student Data

## Technologies Used

- C Programming
- Structure
- Arrays
- Loops
- File Handling

## How to Run

1. Download the source code.
2. Open it in a C compiler.
3. Compile and run the program.
4. Follow the menu instructions.

This is my first C programming project.
